镜头略广角（约24–28mm等效）、机位约腰胸高度、距离大约两三米倒退跟拍。极窄过道里，左右落地柜会贴着画面两边竖条出现。
货品不必两边同时大特写：转向哪侧，哪侧货更清楚；对侧橱窗仍作为完整竖条留在画面里。货从身旁近柜飞出。

【分时段构图】
- 0–20秒：始终完整全身（头到脚）+ 窄街双侧橱窗空间；机位随视线左偏/右偏，但仍保持全身。禁止切成膝上半身。
- 20–22秒：镜头回正中轴，全身中近再走两三步，看清齐套。
- 22–30秒：中轴钉镜，她走向镜头，由全身变成上半身特写再转背影；橱窗可退出，脸部表情优先。

【绝对无人｜全程】
画面中除中央这位主角外，禁止出现任何路人、行人、围观者、店员、远处模糊人影、倒影中的第二个人。
0–3秒开场尤其严格：街道干净空旷，只有她一人。橱窗人台可以有，但无真人脸、不可识别为真人路人。

【镜头语言｜视线反侧运镜 + 全身中近退拍｜极重要】
第一人称手持倒退跟拍，略广角，0–20秒完整全身中近。
核心运镜规则——镜头站在她视线的反侧（视线驱动、反侧机位），连续横移/轻绕，不硬切：
- 她正面看镜头 / 沿中轴走：镜头在中轴正面。
- 她望向或转向左侧橱窗：镜头平滑偏到她的右侧拍摄（约15°–30°），看见她侧脸或3/4脸朝左，同时左侧橱窗与货品更清楚入画。
- 她望向或转向右侧橱窗：镜头平滑偏到她的左侧拍摄（约15°–30°），看见她朝右看的脸，同时右侧橱窗与货品更清楚入画。
- 收束前：镜头平滑回到中轴正面，再钉镜。
始终同时看到「她的脸 + 她正在看的那扇柜」。偏转克制、连贯，像摄影师跟着她的目光轻轻挪步，不是正反打跳切，不是环绕大圈，不是甩镜。
机位大约在她腰到胸口高度，短距后退，不是长街远跟。焦点以人物为主，换装时可短暂落到当前侧货品。

【换装逻辑｜统一用响指卡点｜短距左右取货】
她望向某侧 → 镜头反侧偏移 → 该侧货品可读 → 打响指 → 该侧柜内原件飞出转移到她身上/手中/颈上。
左侧取衣包；右侧取鞋；右侧造型柜改发型并戴上项链。
飞出物必须与对应参考图一致，且从身旁近柜飞出。

【0–3秒｜开场｜中轴正面｜完整全身+双侧橱窗】
她穿着图1开场便装与便鞋、开场低马尾，面对镜头走来，空手、无项链。
镜头在中轴正面，略广角小幅倒退：从头到脚完整入画，人物很高很大；左右落地橱窗同时贴在画面两边竖条里。
无路人、无响指。不要切成膝上半身，也不要大远景小人。

【3–8秒｜第一次响指｜她看左，镜头右偏｜礼服+小包】
保持完整全身。她小步转向并望向左侧成衣橱窗。
镜头随视线平滑偏到她的右侧拍摄：她的脸朝左清晰可读，左侧图2礼服与小包清楚入画；右侧橱窗仍可留在画面边缘。
打响指：图2礼服从左侧近柜飞出裹合上身，开场便装被替换；图2小包飞到她手中。
短暂展示裙长、开衩、开场便鞋、手中小包。人物仍是图1。不要改成半身，不要硬切机位。

【8–13秒｜第二次响指｜她看右，镜头左偏｜晚宴鞋】
保持完整全身（脚必须在画面里）。她转向并望向右侧鞋柜。
镜头平滑从右侧位移到她的左侧拍摄：她的脸朝右清晰可读，右侧图3鞋子清楚入画；左侧橱窗留在左缘。
打响指：图3鞋子从右侧近柜飞向脚面完成替换，细带贴合脚踝。
全身能看见新鞋、裙摆、手中包。礼服与小包保持图2。连续横移，不跳切。

【13–20秒｜第三次响指｜她仍看右，镜头保持左偏｜发型+项链】
保持完整全身。她面向右侧造型镜柜（与鞋柜同侧邻近），对应图4可读。
镜头继续在她的左侧反侧机位（可轻微再稳一点），看见她朝右的脸 + 右侧造型柜。
打响指：头发变为图4晚宴大波浪；图4项链同时戴上，链条与坠饰清晰。
只改头与颈饰，不换脸。衣、包、鞋保持。禁止漏项链。
换完即全身齐套对齐图5。不要切半身，不要远景走秀。

【20–30秒｜收束｜镜头回正→钉镜走近特写→背影｜必须以图5为准】
完整造型全程锁定图5：图2礼服 + 图2小包 + 图3鞋 + 图4发型 + 图4项链，脸与身材仍为图1。禁止缺项链、缺包、发型回退。

20–22秒：造型已齐。镜头平滑回到中轴正面，仍以完整全身中近对镜头走两三步，头到脚+双侧橱窗还在，看清齐套。

22–26秒：摄影师在中轴站住，镜头固定，不再后退也不再左右偏。她继续朝镜头走来，人越来越大，全身自然变成上半身特写，构图接近图4：头、肩、项链、深V、手中小包，脸是主体；背景橱窗可虚化或退出。特写表情：对镜头轻轻眨眼，随后嘴角慢慢扬起克制浅笑，像确认“可以出门了”，从容成熟，不大笑、不抛媚眼、不张嘴说话。

26–30秒：她不站定摆拍，继续向前，从镜头/摄影师身旁擦过。镜头基本固定或极轻跟随，由正脸特写转为背影：晚宴大波浪、细肩带、及地裙摆、手中小包，沿窄街向深处走去。以背影离去结束，不要定格正脸海报。

【物理真实性】
缎面礼服有重量与开衩摆动；小包在手中有重量；鞋子贴合；头发轻晃；项链随动作有轻微真实晃动。
三次响指分开完成，顺序固定：左衣包 → 右鞋 → 右发+项链。禁止一次换完。禁止走很长的街才换下一项。

【摄影与氛围】
白天自然光 + 橱窗香槟暖柜灯，真实光学成像。0–20秒略广角、全身清晰、反侧机位带出当前橱窗；22秒后浅景深推向面部。
高级街头时尚广告质感，日常到晚宴反差强，生活化手持。
